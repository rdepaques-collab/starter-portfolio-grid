# Remix of Remix of Remix of Remix of Remix of My Blank Canvas

Je ne veux plus de projets de démonstration. Crée un portfolio vide avec 30 emplacements numérotés de 1 à 30. Chaque emplacement doit contenir une image vide, un titre, une catégorie et une description. Je remplacerai chaque emplacement par mes propres projets plus tard. Ne modifie pas le reste du site.

This project was built with [Lovable](https://lovable.dev).
